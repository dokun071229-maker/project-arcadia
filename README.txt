PROJECT ARCADIA 3D WORLD v2

실행:
- HTTPS 정적 호스팅에 폴더 내용을 업로드한 뒤 index.html 접속.
- Three.js 모듈을 jsDelivr CDN에서 가져오므로 3D 장면을 보려면 인터넷 연결이 필요합니다.
- PWA 설치와 서비스워커는 HTTPS 환경에서 동작합니다.

기능:
- Three.js 기반 절차 생성 3D 도시, 회전/확대/축소 카메라
- 도시 선택, 주야간 기반을 확장할 수 있는 실시간 세계 시계
- 1x: 실제 1초당 가상 1분, 10x/60x 가속, 일시정지
- 앱을 닫은 동안 경과 시간 반영(시작 시 최대 30일 catch-up)
- 인구·경제·사회 지표와 사건 로그
- 주요 시민 목록, JSON 백업/복원, 로컬 자동 저장

중요한 한계:
- 현재 3D 도시는 절차 생성된 시각적 프로토타입이며 시민 개개인의 3D 아바타/실제 경로탐색은 아직 구현되지 않았습니다.
- 사건과 지표는 간단한 확률 기반 시뮬레이션입니다. 자율 AI 시민, 정교한 교통/경제/정치 모델은 다음 단계입니다.
- 데이터는 이 기기의 브라우저 로컬 저장소에 보관됩니다. 클라우드 동기화와 다중 기기 영구 저장은 별도 백엔드가 필요합니다.
- Three.js CDN 사용으로 첫 로딩에는 인터넷이 필요합니다.
